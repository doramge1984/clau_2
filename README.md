# 클로드로 세특 쓰기 연수 (웹 교안)

2026학년도 학교생활기록부 기재요령(고등학교)을 바탕으로, 클로드 데스크톱 앱에서 교과 세부능력 및 특기사항(세특) 초안을 쓰는 과정을 따라 해 보는 웹 교안입니다.

## 구성

| 단계 | 내용 |
|---|---|
| 00 | 흐름과 준비 |
| 01 | 일반 채팅: 기재요령에서 세특 지침 뽑기, 예시 보고서로 세특 써 보기 |
| 02 | 데이터 정제: 학생 자료를 학번별 엑셀 한 장으로 |
| 03 | 프로젝트: 정리 표와 평가계획으로 반 전체 세특 쓰기 (오늘의 목표) |
| 04 | 내 세특 스킬 (선택): 준비된 스킬로 써 보기, 나만의 스킬 만들기 |
| + | 추가 팁: 구글 시트 AI 함수, 제미나이노트북 |

## 보는 방법

- `index.html` 파일 하나로 동작합니다. 브라우저로 열거나 GitHub Pages로 공개하면 됩니다.
- 실습 자료(예시 보고서, 평가계획, 스캔본, 스킬 파일 등)는 각 단계의 받기 버튼을 누르면 브라우저에서 바로 만들어져 저장됩니다. 일부 파일 생성에 cdnjs의 라이브러리(JSZip, SheetJS, jsPDF)를 불러오므로 인터넷 연결이 필요합니다.

## GitHub Pages로 공개하기

1. 이 폴더의 파일(`index.html`, `README.md`, `.nojekyll`)을 저장소에 올립니다.
2. 저장소 **Settings → Pages**에서 Source를 `main` 브랜치의 `/ (root)`로 정합니다.
3. 잠시 뒤 표시되는 주소로 접속합니다.

## 자료에 대해

- 실습용 학생 자료는 연수용 예시입니다. 이름은 지우고 학번은 가상으로 바꿨습니다.
- 세특 초안은 생성형 AI의 도움을 받은 초안입니다. 학생의 실제 수행과 대조하고 기재요령을 지켰는지 교사가 확인한 뒤 입력해야 합니다 (기재요령 p.19).
